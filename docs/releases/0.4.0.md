# OpenForma 0.4.0

This release packages the engineering-domain work merged through PR #48.

## Highlights

- Independent domain discovery, selection, authoring, composition and validation.
- ChemicalIR, ProcessIR and ThermalIR with explicit provenance and bounded evaluations.
- Exact stoichiometric batch bounds, limiting reactants and theoretical yields.
- Resumable, guided external-agent generation through the shared SDK, CLI and MCP surface.
- Revision-pinned semantic-to-geometry bindings and native CAD inspection.
- Deterministic PlatformIO firmware scaffolding and expanded biological evidence workflows.

## Packages

- Python: `caid-forma-core==0.4.0`.
- React GUI: `@isayahc/forma-gui@0.1.3` (independently versioned).

The HTTP MCP backend lives in this repository under `apps/api`; installing the
Python core wheel alone does not install the backend application. To run this
release locally, check out `v0.4.0`, run `uv sync --project apps/api --frozen --no-dev`,
and launch from the repository root:

```powershell
$env:FORMA_AUTH_MODE = "local"
$env:FORMA_DEV_MODE = "true"
$env:DATABASE_BACKEND = "sqlite"
uv run --project apps/api --frozen --no-dev python -m uvicorn apps.api.main:app --host 127.0.0.1 --port 8000
```

Connect an MCP client to `http://127.0.0.1:8000/mcp`. Local authentication mode is
for a loopback-only local backend. Domain validation and bounded evaluations do
not establish physical feasibility or executable machine behavior.
